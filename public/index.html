📋 Gestion des Présences

Solution simple pour enregistrer les présences des étudiants via QR code

👨‍🏫 Enseignant

Générez un QR code pour votre séance de cours. Les étudiants scannent ce code pour enregistrer leur présence.

Accéder à l'interface enseignant

🎓 Étudiant

Scannez le QR code affiché par votre enseignant pour valider votre présence.

Accéder à l'interface étudiant

Comment ça marche ?

  1. L'enseignant crée une séance et génère un QR code unique.
  2. Les étudiants présents scannent le QR code avec leur téléphone.
  3. Les données de présence sont automatiquement enregistrées dans Google Sheets.
  4. L'enseignant peut consulter les présences à tout moment.

Technologies utilisées : PWA, QR Code, Google Forms, Google Sheets.
