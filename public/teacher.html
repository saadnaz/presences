QR Code de présence

Montrez ce QR code aux étudiants présents. Ils doivent le scanner avec leur téléphone.

Instructions : Le QR code contient un lien vers un formulaire Google Forms pré-rempli avec les informations de la séance. Chaque étudiant qui scanne sera redirigé vers ce formulaire pour soumettre sa présence.

Comment utiliser ?

  1. Remplissez les détails de la séance ci-dessus.
  2. Cliquez sur "Générer le QR code". Un QR code unique sera créé.
  3. Montrez le QR code aux étudiants (affichage projeté, téléphone, ou impression).
  4. Les étudiants scannent le code avec leur appareil photo.
  5. Ils seront dirigés vers un formulaire Google Forms pour confirmer leur présence.
  6. Les données seront automatiquement enregistrées dans un Google Sheets.

Conseil : Vous pouvez aussi partager l'URL directement avec les étudiants (via Google Classroom, email, etc.).
