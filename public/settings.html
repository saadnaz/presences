Configurez votre intégration Google Forms et Google Sheets

Configuration du formulaire Google Forms

Pour que l'application fonctionne, vous devez créer un formulaire Google Forms et indiquer ci‑dessous son URL de base ainsi que les IDs des champs. Guide détaillé.

Profil enseignant

Choisissez un profil pour gérer ses paramètres spécifiques.

L'URL complète de votre formulaire Google Forms (sans paramètres).

⚠️ Sheet déconnecté ou formulaire retravaillé ?

Si vous avez effacé ou supprimé le Google Sheet, ou retravaillé votre formulaire, il faut :

  1. Dans Google Forms → onglet Réponses → cliquer l'icône verte Sheets → Créer une nouvelle feuille
  2. Re-extraire les IDs des champs avec le bookmarklet ci-dessous (les IDs changent si le formulaire a été modifié)
  3. Re-enregistrer la configuration ici
⚠️ Si votre formulaire a plusieurs sections/pages (ex. : section 1 = séance, section 2 = étudiant), sélectionnez le bon nombre. Sans ça, les champs des sections 2+ ne seront pas enregistrés dans Google Sheets.

🖥️ Sur ordinateur (Chrome / Firefox / Edge)

Affichez la barre de favoris (Ctrl+Shift+B), puis faites glisser ce bouton dedans :

📋 Extraire les IDs du formulaire

📱 Sur mobile (iOS Safari / Android Chrome)

Le glisser-déposer n'est pas possible. Procédez ainsi :

  1. Cliquez sur Copier le code ci-dessous
  2. Mettez n'importe quelle page en favori (via le menu du navigateur)
  3. Modifiez ce favori (appui long → Modifier) et remplacez l'URL par le code copié
  4. Renommez-le "Extraire IDs" pour le retrouver facilement
✅ Copié !

Étape 2 — Ouvrez votre formulaire Google Forms dans un onglet (page /viewform).
Étape 3 — Cliquez sur le favori. Une fenêtre affiche les champs et leur ID, avec le nombre de sections.
Étape 4 — Copiez tout (Ctrl+A, Ctrl+C) et collez ci-dessous. L'import détectera automatiquement les champs.

Compte Google administrateur

Les données seront stockées dans le Google Sheets lié à votre formulaire. Assurez‑vous que le formulaire a été créé avec le compte Google que vous souhaitez utiliser comme administrateur.

Note : L'application ne stocke pas vos identifiants Google. Seul le formulaire Google Forms est utilisé pour collecter les soumissions.

Pour changer de compte administrateur, créez un nouveau formulaire avec le compte souhaité et mettez à jour les paramètres ci‑dessus.
