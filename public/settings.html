Compte Google administrateur

Les données seront stockées dans le Google Sheets lié à votre formulaire. Assurez‑vous que le formulaire a été créé avec le compte Google que vous souhaitez utiliser comme administrateur.

Note : L'application ne stocke pas vos identifiants Google. Seul le formulaire Google Forms est utilisé pour collecter les soumissions.

Pour changer de compte administrateur, créez un nouveau formulaire avec le compte souhaité et mettez à jour les paramètres ci‑dessus.
