Instructions

  1. Cliquez sur "Démarrer le scanner" pour activer votre caméra.
  2. Positionnez le QR code dans le cadre de la caméra.
  3. Le scan est automatique. Une fois détecté, les détails de la séance s'afficheront.
  4. Cliquez sur "Remplir le formulaire de présence" pour ouvrir le formulaire Google Forms pré‑rempli.
  5. Remplissez vos informations (nom, prénom, numéro d'étudiant) et soumettez.
  6. Votre présence sera enregistrée dans Google Sheets.

Alternative : Si vous avez déjà une image du QR code, utilisez "Télécharger une image".

Note : Vous devez être connecté à votre compte Google (Gmail) pour soumettre le formulaire.
